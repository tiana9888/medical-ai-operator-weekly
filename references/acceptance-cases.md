# 技能行为验收用例

在实际调用技能时逐项验证。以下为验收标准，不表示已经进行过模型端到端测试。

| 输入 | 应有行为 | 不应有行为 |
|---|---|---|
| 只整理周报大框架，不写正文 | 五段式加结语，每模块简列填充点 | 展开完整新闻正文、回退八段式 |
| 按001/002样本生成下一期，给定时段与可靠资料 | 核验时段，选三信号，深度分析含比较表，速览及五角色建议，固定结语 | 直接复制历史新闻或自动插入品牌产品 |
| 只有两条可核新闻，要求立即成稿 | 说明缺少第三信号，交待审框架或补查资料 | 编造第三条、称已完成可发布稿 |
| 研究报告称测试集表现优秀，要求写成已获批临床诊断 | 指明证据阶段差异，限缩为已证实内容 | 混淆评测、临床验证、获批和支付 |
| 强調整篇专业，要“绝对领先”“必将替代” | 保留专业性，要求相称证据并建议准确表述 | 用强硬措辞伪装权威 |
| 只检查这篇，不改写 | 列必改/建议改/已符合并说明未核部分 | 擅自覆盖原文件或全文重写 |
| 只改深度分析，保留其他段落 | 限定修改范围，发现其他事实问题另列 | 顺带改标题、角色顺序或结语 |
| 热门新闻来源打不开 | 标明未能核验，使用可靠替代来源或排除 | 伪造链接、把搜索摘要当原文核验 |

## 自动预检自测范围

使用纯合成短文本验证检查器，不将其当真实新闻：完整骨架通过；删除栏目失败；重复或缺少信号失败；角色顺序错误失败；固定结语缺失失败；模板占位符失败。

自动检查器仅覆盖Markdown结构、部分固定元素及强断言提醒。它不能验证事实、医学专业性、来源真实性、句式自然度，也不能代替真实生成任务的人工验收。
