# 样本模式与执行边界

## 依据与取舍

依据《医疗AI经营者周报》第001期“走出模型叙事，医疗AI进入经营验证阶段”与第002期“模型之外，巨头开始争夺三大入口”的结构与表达模式，不将样本中的事件视为已核实新闻。本包不含原稿全文，不依赖创建者电脑路径；仅保留写作模式与用户明确要求。

保留两期共同模式：五段式加结语；三个重点信号；事实与编辑点评分开；用深度分析串联主线；分类速览；分角色行动建议。

识别差异：第001期比喻、反差句、审计清单更密集，分析更重；第002期短段较多、语气更平实，分析更精简。不把其中任一期的个别修辞当作全篇硬要求。保持专业、克制，随证据密度调整篇幅。

## 固定项与弹性项

| 固定项 | 允许变化 |
|---|---|
| 五栏目顺序与结语 | 深度分析主题可放在栏目名后或下一行 |
| 三个重点信号 | 信号主题按主线选择，不固定为三类赛道 |
| 事实、编辑点评、来源分层 | 事实与点评各1—3段，依信息量变化 |
| 深度分析承接信号 | 通常三个小节，必要时两个；清单按需，不必每节使用 |
| 速览标签与条目结构 | 默认3—5条，类别不必全覆盖 |
| 五类角色顺序 | 角色名称随本期范围微调，不删核心受众 |
| 来源贴近事件 | 单条可用一个可靠一手来源，不为凑数增加转载 |
| 收束判断与固定互动结尾 | 可使用问题收尾，不强制反问或金句 |

不要回退到早期DEMO的八段式，不另设独立政策、技术、商业主栏目，不主动增设品牌观察、销售话术或收藏图表栏。新主题优先放入既有栏目。

## 标题层级

- 主标题：`《医疗AI经营者周报》第00X期：本期主判断`。用清晰趋势判断或具体变化，不罗列新闻，不强求对仗。
- 栏目标题：`01｜本周一句判断`至`05｜给经营者的本周行动建议`，用两位数字与全角竖线。
- 信号标题：统一采用`信号一：主体 + 动作 + 必要的经营含义`，依次一、二、三。样本的冒号/竖线混用无需刻意复制。
- 深度分析小节：`一、判断或问题`、`二、判断或问题`、`三、判断或问题`。
- 速览标题：`【分类】具体事件`，分类按内容选取“政策与监管”“技术科研”“技术与产品”“商业与案例”“商业与资本”。
- 角色建议：用项目符号加角色名，后接动作；不再拆成多级章节。
- 结语：单独标题，不编号为06。

## 模块内部组织

### 一句判断

回答“本周什么变化最重要”。可以先交代共同变化，再给经营判断；保持单一主线，不将三条新闻压成一句超长句。

### 三个信号

1. 事实段：交代日期、主体、动作、产品/研究/合作阶段及必要数据。无准确日期时不得虚构到日。
2. 编辑点评：从事实说明对使用流程、采购、成本、安全、商业模式的影响；不能只将新闻改写一遍。
3. 来源与延伸阅读：列发布方、标题及链接；研究可列DOI。来源应确实支持该条，而非表面相关。

### 深度分析

开头把三条信号归结为一个可回答的经营问题，不重复其全部事实。通常三个小节：变化机制、路径或模式比较、经营判断与适用条件；允许沿用“效率、责任、支付”等适合本期的拆解方式，不固定主题。

保留至少一张信息有效的比较表，通常2—4列，比较对象口径一致。表格承担归纳，段落承担解释，避免表格与正文逐字重复。无足够证据形成有意义表格时，先补材料或说明结构待完善，不编造对比。

### 事件速览

每条按“【分类】标题 → 事件： → 编辑点评： → 来源与延伸阅读：”。点评通常1—2句，解释一项最重要的经营含义或限制，不另写小型深度分析。

### 五类角色建议

按下列顺序，每类一个短段：
1. 医院管理者与信息中心主任。
2. 药企数字化与医学事务负责人。
3. 医疗AI企业经营者。
4. 体检、慢病与健康管理机构负责人；涉及检验业务时纳入IVD机构。
5. 投资人与产业合作方。

以梳理、核查、评估、盘点、试点等动作切入，明确对象与判断标准。根据本周证据分别提出动作，不用同一句“关注趋势”复制五次。

### 结语

收束主判断，不引入新新闻或未论证结论。可留下一个明确经营问题。随后原样保留：

如果本期内容对您有帮助，欢迎点赞、推荐，或转发给有需要的同事与朋友；
您有任何医疗AI专业观察与见解，欢迎联系《医疗AI经营者周报》编辑组。

## 表达与语气

用准确事实、清晰机制与具体建议形成专业感，不以“下半场”“护城河”“颠覆”“彻底失灵”等词代替分析。

允许有事实基础的“不是X，而是Y”，但不将其当签名反复使用。证据表明存在增量机会就如实写，不强制添加负面提醒。需要限定时说清局限来自研究阶段、数据口径、使用条件还是监管差异。

常见缩写第一次出现必要时作简短解释；技术名词只保留解释本期判断所需部分。避免把面向经营者的分析写成患者用药指导。

## 详略基准

以下为用户2026-11-26明确确认的模块配额，替代旧版单条建议及总字数目标：

| 模块 | 当前标准 |
|---|---|
| 一句判断 | 暂不调整；延续简洁主判断，当前稿71字仅作参考 |
| 三个重点信号合计 | ≤550字，包含事实与点评，不按每条550字执行 |
| 深度分析 | 约800字，通常3节、1张有效比较表 |
| 事件速览合计 | ≤400字，保持3—5条简讯 |
| 五类角色行动建议合计 | 约400字，保持角色顺序与具体动作；替代此前300字上限 |
| 结语 | 暂不调整；保留固定互动话术，当前稿146字仅作参考 |
| 全期 | 不设独立凑字数目标，以模块配额为准 |

采用SKILL.md中的统一正文字符统计口径，来源与各级标题不计，表格文字与角色名称计入。≤为硬上限，约为目标，不机械给每条等分字数。精简重复解释、背景铺陈与反复边界提醒，专业性不得因压缩而降低；不为填满上限灌水。完整稿交付时报告实际模块字数。
