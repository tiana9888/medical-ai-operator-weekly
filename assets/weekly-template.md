# 周报填充模板

仅在框架模式保留占位符。成稿模式须替换占位符并核实事实；材料不足时明确为待审框架，不称可发布稿。

成稿目标：每个信号正文约300字、合计约900字，不设硬上限；深度分析约800字；速览不超过5条、每条约160字（事件与编辑点评合计，不含标题、来源）；五角色行动建议合计约400字。一句判断与结语保持简洁。按SKILL.md口径统计正文，计入标点及英数字符，排除标题、来源、空白及Markdown格式符号，计入表格与角色名称；交付前核对每条信号及模块字数，不凑字数。

写正文前先检索比较候选：影响范围与程度、实质性、经营参考价值、时效性与证据质量 → 选三个最重要或最有价值事件 → 再判断主线。弱关联时分别说明各自价值，深度分析聚焦最值得深入的一个经营问题。候选比较是编辑底稿，不必出现在文章中。
